# Lab 04 - ADC Motor Control and UART Reporting

STM32F401 lab project extending the motor-control UART protocol with ADC-based speed/reporting behavior. A C# WinForms COM application archive has been extracted and preserved.

## What It Implements

The firmware reads ADC1, maps ADC values to motor speed, uses TIM1 PWM for motor control, communicates through USART2, and sends ADC report frames using the lab UART protocol.
